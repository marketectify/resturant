# Master Foods & Pakwan Centre (MERN demo)
1. Install MongoDB locally (or use Atlas), copy `server/.env.example` to `server/.env`
2. `npm run install:all` then `npm run dev`
3. Site: http://localhost:5173  |  Admin: http://localhost:5173/#/admin  (password in .env, default master123)
Edit business details (phone, address, hours, map) in `client/src/config.js`.
