Put real food photos here. File name = item name in lowercase with dashes, .jpg

  Chicken Biryani        -> chicken-biryani.jpg
  Chicken Tikka Chest    -> chicken-tikka-chest.jpg
  Hot & Sour Soup        -> hot-sour-soup.jpg

Square or 4:3 photos, about 800px wide, under 200 KB each, work best.
An item with no photo here automatically shows its emoji tile instead.
(An image URL set in shared/menu.json or the admin form always wins over this folder.)
